# 03 — Windows

## Goal
Become comfortable supporting and troubleshooting Windows PCs.

## Study areas
- Windows 10/11 administration
- Users and permissions
- Settings and Control Panel
- Task Manager
- Services
- Event Viewer
- Device Manager
- Windows Update
- Networking tools
- PowerShell basics
- Remote support concepts

## Move on when
- I can troubleshoot common Windows issues without a tutorial.
- I can explain why I use each troubleshooting step.
- I can use basic PowerShell commands.
