# IT Learning Journey — Dario

My 12-month journey from rusty IT knowledge to my first professional IT job.

## How this repository works

- **01–12** = the learning roadmap in order
- **Labs** = hands-on practice
- **Projects** = things I build myself
- **Certifications** = certificates, badges, exam preparation and results
- **Career** = CV, job applications and interview preparation
- **Notes** = important concepts I want to remember

## Current goal

Become employable for an entry-level IT role while rebuilding my IT foundations.

## Study rule

**Learn → Practice → Build → Prove → Move on**

I do not move to the next major topic just because I finished a video. I move on when I can complete the practical checklist for the current topic.
