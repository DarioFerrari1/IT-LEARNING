# 09 — Cybersecurity

## Goal
Explore cybersecurity after building the required IT, networking, Windows and Linux foundations.

## Study areas
- Security fundamentals
- Threats and vulnerabilities
- Authentication and access control
- Network security
- Windows/Linux security
- Logs and monitoring
- Basic incident response
- Security tools
- TryHackMe practical labs

## Important
Only practise against systems/labs you own or are explicitly authorized to test.

## Move on when
- I understand common security concepts and terminology.
- I can explain basic defensive controls.
- I can complete beginner security labs and explain what I did.
- I can identify whether cybersecurity is an area I genuinely enjoy.
