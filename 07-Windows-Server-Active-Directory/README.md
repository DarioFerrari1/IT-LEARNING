# 07 — Windows Server & Active Directory

## Goal
Understand the fundamentals of business Windows environments.

## Study areas
- Windows Server concepts
- Active Directory
- Domains
- Users and groups
- Group Policy
- DNS in Active Directory
- File shares and permissions
- Remote Desktop
- Basic administration and troubleshooting

## Labs
Use virtual machines where possible. Document every lab and what you learned.

## Move on when
- I can explain what a domain and Active Directory are.
- I can create/manage basic users and groups in a lab.
- I understand the relationship between AD and DNS.
- I can troubleshoot basic account/permission problems.
