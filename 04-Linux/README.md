# 04 — Linux

## Goal
Learn Linux fundamentals and become comfortable working in a terminal.

## Study areas
- Linux filesystem
- Terminal and shell
- Files and directories
- Permissions
- Users and groups
- Processes
- Package management
- Networking commands
- SSH
- Basic Bash scripting

## Labs
Store VM/lab notes in `labs/`.

## Move on when
- I can navigate and manage files from the terminal.
- I understand permissions and users/groups.
- I can install software and inspect processes.
- I can connect to a Linux machine with SSH.
