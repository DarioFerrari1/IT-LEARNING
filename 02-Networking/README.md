# 02 — Networking

## Goal
Build a solid practical networking foundation.

## Study areas
- OSI and TCP/IP models
- IPv4 and subnetting
- MAC addresses
- Switches and routers
- DHCP and DNS
- Default gateways
- TCP vs UDP
- Ports
- NAT
- Wi-Fi
- Troubleshooting with ping, ipconfig, nslookup and tracert
- Cisco Packet Tracer

## Labs
Use `labs/` for Packet Tracer and troubleshooting exercises.

## Move on when
- I can explain how a device reaches another device on a network.
- I can configure a basic Packet Tracer network.
- I can identify common DNS/DHCP/IP problems.
- I can troubleshoot basic connectivity logically.
