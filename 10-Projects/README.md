# 10 — Projects

This folder contains projects I build myself to prove practical ability.

## Project standard
Every project should include:
- A clear README
- Goal/problem being solved
- Technologies used
- Setup instructions
- What I learned
- Screenshots or diagrams where useful
- Problems encountered and how I solved them

## Planned project progression
- Beginner IT/troubleshooting project
- Networking lab
- Linux/home-lab project
- Python automation project
- Windows/Active Directory lab
- Cloud project
- Cybersecurity project

Projects should become increasingly independent. Avoid simply copying tutorials.
