# 06 — Git & GitHub

## Goal
Learn the workflow used to manage and present IT projects.

## Study areas
- Git basics
- Repositories
- Commits
- Branches
- Merge and pull requests
- .gitignore
- README files
- GitHub project documentation

## Move on when
- I can create a repository.
- I can clone, edit, commit and push changes.
- I understand branches at a basic level.
- I can document a project clearly for an employer.
