# 08 — Cloud

## Goal
Understand cloud fundamentals before deciding whether to move toward cloud/infrastructure.

## Study areas
- Cloud concepts
- IaaS, PaaS and SaaS
- Virtual machines
- Storage
- Networking in the cloud
- Identity and access
- Azure fundamentals
- Monitoring and basic security

## Certifications
Track Microsoft certification preparation and results in `../11-Certifications/`.

## Move on when
- I can explain the main cloud service models.
- I understand basic Azure services and identity concepts.
- I can complete beginner Azure labs without blindly copying steps.
