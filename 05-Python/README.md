# 05 — Python

## Goal
Rebuild Python from beginner level and use it for useful IT automation.

## Study areas
- Variables and data types
- Conditions
- Loops
- Functions
- Lists, dictionaries and sets
- Files
- Exceptions
- Modules
- Virtual environments
- APIs and JSON
- Basic automation

## Projects
Build small original scripts and document them in `projects/`.

## Move on when
- I can write small scripts without following a tutorial line by line.
- I can debug basic Python errors.
- I can read/write files and work with JSON.
- I can build a small useful automation script.
